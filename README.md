# CryptoSentinel

Real-time wedge & breakout pattern trading system on Binance Spot Testnet.

Quick start:

1. Create virtual env and activate:

```bash
python -m venv .venv
source .venv/bin/activate
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Copy `.env.example` to `.env` and add testnet keys.

4. Run engine:

```bash
python main.py
```

5. Run dashboard:

```bash
streamlit run dashboard.py
```
